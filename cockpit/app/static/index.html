Guide & field-measurement workflow

How the workflow works

  • At the top, the campaign ring shows overall progress — setup already counts, so the ring never starts at 0%.
  • In the Overview, tap the device you're currently holding (or the gateway) — this opens "Selected device / gateway" right below it and shows the live signal immediately, even without a running run.
  • Place: floor/room are pre-filled (last known location, or the gateway's floor), and the antenna remembers your last choice. Optionally take up to 3 photos — your own photo collection grows with every location.
  • Start run — 24 h · SF7→SF9→SF12 · 5-min interval — one tap starts the full sweep; under "Customize" you can change the duration, interval and SF sequence. Only possible once both the device and the gateway are placed.
  • The glowing SF bar shows the sweep live: completed stages ✓, the current stage pulses, future stages stay dark. Progress is always shown relative to the overall plan (e.g. "14 h of 24 h"), never in isolation.
  • Live PDR per SF shows delivery reliability for each spreading factor — both uplink (received/expected) and downlink (ACK rate from confirmed test downlinks) — the coverage metric that actually matters, since RSSI barely changes with SF.
  • When the planned duration elapses, the run ends automatically — the card briefly celebrates with a pulse and shows "done ✓".
  • Relocate: moving to the next spot? Tap "Place / Relocate" again — if a measurement is still running it first asks you to confirm, then closes it and starts a new one right away.
  • Done early? "Stop run" asks for confirmation and shows exactly which SF stages would still be missing — so data loss is never a surprise.
  • Moving the gateway while measurements are still running first shows a warning with exactly what would be lost per device — confirm "Move anyway" to end them in a controlled way (data is kept) and continue to the move dialog.

Step by step

  1. Tap a device in the Overview (or pick one in the selector at the top) — the live signal appears immediately.
  2. "Place / Relocate" → check/adjust the pre-filled fields, pick the antenna, optionally add photos → Save.
  3. "Start run — 24 h · SF7→SF9→SF12 · 5-min interval" (the gateway must be placed too), or pick a custom duration/interval/SF sequence under "Customize".
  4. The sweep runs automatically through SF7 → SF9 → SF12 (or your chosen sequence) — the glowing bar shows progress, always relative to the total duration.
  5. Device moved? Tap "Place / Relocate" again — confirm stopping the running measurement, and it closes the run and starts a new one right away.
  6. Done early? "Stop run" (with a confirmation prompt). If the duration runs out, the run ends by itself and the card shows "done ✓". Each run's CSV is available for download in History.

Metrics & color legend

RSSI (dBm) — received signal strength at the gateway

> −80 dBm: excellent
−80 to −110 dBm: good
−110 to −120 dBm: marginal
< −120 dBm: poor (floor −140 dBm)

SNR (dB) — how far LoRa receives below the noise floor

≥ 0 dB: comfortable
−10 to 0 dB: good
−15 to −10 dB: tight
< −15 dB (demod floor −20 dB)

PDR — packet delivery ratio (per SF, uplink & downlink)

≥ 99 %: excellent
≥ 80 %: adequate for heating control
50–80 %: problematic
< 50 %: coverage gap

CAF — foreign airtime fraction (RF coexistence)

< 2 %: green — uncritical
2–10 %: yellow — keep an eye on it
> 10 %: red — critical

Panels at a glance

  • Campaign status — overall progress as a ring; never at 0%, grows with every device placed/started/finished.
  • Overview — one card per device + gateway: location, run status, packets, live values, SF-sweep bar. Tapping selects it and opens the detail panel below.
  • Selected device / gateway — live signal visible immediately, location, photos, run status, sweep progress, PDR per SF, device status (last packet, measured send interval, config downlink); Place/Relocate, start/stop run, move gateway. The selector at the top right is an alternative to tapping the card.
  • RF Environment — always running passively, no start/stop needed, recorded continuously; a spectrum survey of what the gateway overhears: a channel × SF heatmap of foreign traffic, detected networks (TTN/private/other), a scrollable foreign-device list, nearby vendors (from joins, best-effort), band busyness (frames/min + MType breakdown), and a CSV download of the full log.
  • Device registration (collapsible) — register new OTAA devices in ChirpStack; also holds the bulk Vicki commands (set interval / read version) for all registered devices.
