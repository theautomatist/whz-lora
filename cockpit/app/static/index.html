Anleitung & Feldmess-Workflow

So funktioniert der Workflow

  • Oben zeigt der Kampagnen-Ring den Gesamtfortschritt — Setup zählt schon mit, der Ring startet nie bei 0 %.
  • In der Übersicht das Gerät antippen, das du gerade in der Hand hast (oder den Gateway) — das öffnet direkt darunter „Ausgewähltes Gerät / Gateway" und zeigt sofort das Live-Signal, auch ohne laufenden Run.
  • Platzieren: Etage/Raum sind vorausgefüllt (letzter bekannter Standort bzw. Gateway-Etage), Antenne merkt sich die letzte Wahl. Optional bis zu 3 Fotos aufnehmen — deine eigene Foto-Sammlung wächst mit jedem Standort.
  • Run starten — 24 h · SF7→SF9→SF12 · 5-min-Intervall — ein Tap startet den vollen Sweep; unter „Anpassen" lassen sich Dauer, Intervall und SF-Ablauf ändern. Nur möglich, wenn Gerät und Gateway platziert sind.
  • Die glühende SF-Leiste zeigt den Sweep live: erledigte Stufen ✓, die aktuelle Stufe pulsiert, künftige bleiben dunkel. Fortschritt wird immer im Verhältnis zum Gesamtplan angezeigt (z. B. „14 h von 24 h"), nie isoliert.
  • Läuft die geplante Dauer ab, endet der Run automatisch — die Karte feiert kurz mit einem Puls und zeigt „fertig ✓".
  • Umsetzen (Relocate): Zum nächsten Standort? „Platzieren / Umsetzen" erneut antippen — schließt den laufenden Run automatisch und startet direkt einen neuen.
  • Vorzeitig fertig? „Run stoppen" fragt zur Sicherheit nach, welche SF-Stufen dabei noch fehlen — Datenverlust ist so nie eine Überraschung.
  • Gateway bewegen geht nur, wenn kein Run mehr läuft — sonst zeigt eine Warnung genau, was pro Gerät verloren geht; „Trotzdem umsetzen" bricht die Runs kontrolliert ab (Daten bleiben erhalten).

Schritt für Schritt

  1. In der Übersicht das Gerät antippen (oder oben im Auswahlfeld wählen) — Live-Signal erscheint sofort.
  2. „Platzieren / Umsetzen" → vorausgefüllte Felder prüfen/anpassen, Antenne, optional Fotos → Speichern.
  3. „Run starten — 24 h · SF7→SF9→SF12 · 5-min-Intervall" (der Gateway muss ebenfalls platziert sein) oder unter „Anpassen" Dauer/Intervall/SF-Ablauf wählen.
  4. Der Sweep läuft automatisch durch SF7 → SF9 → SF12 (oder den gewählten Ablauf) — die glühende Leiste zeigt den Stand, immer im Verhältnis zur Gesamtdauer.
  5. Gerät bewegt sich? Erneut „Platzieren / Umsetzen" antippen — schließt den Run automatisch und startet direkt einen neuen.
  6. Vorzeitig fertig? „Run stoppen" (mit Sicherheitsabfrage). Läuft die Dauer ab, endet der Run selbst und die Karte zeigt „fertig ✓". CSV je Run steht im Verlauf zum Download bereit.

Phasen

  • Phase 1 · SF9 (DR3): Abdeckung über viele Standorte screenen; Airtime ~144 ms/Paket.
  • Phase 2 · SF12 (DR0): Reserve / Worst-Case; robustester Modus, misst die Funk-Reserve.
  • Normal · ADR: Kein Messmodus — SF wird vom Netz geregelt.

Kennzahlen & Farblegende

RSSI (dBm) — Empfangsstärke am Gateway

> −80 dBm: sehr gut
−80 bis −110 dBm: gut
−110 bis −120 dBm: grenzwertig
< −120 dBm: schlecht (Grenze −140 dBm)

SNR (dB) — LoRa empfängt unter dem Rauschen

≥ 0 dB: komfortabel
−10 bis 0 dB: gut
−15 bis −10 dB: knapp
< −15 dB (Demod-Grenze −20 dB)

PDR — Paketempfangsrate (Uplink)

≥ 99 %: exzellent
≥ 80 %: für Heizung ausreichend
50–80 %: problematisch
< 50 %: Abdeckungslücke

CAF — Fremd-Airtime-Anteil (Koexistenz)

< 2 %: grün — unkritisch
2–10 %: gelb — beobachten
> 10 %: rot — kritisch

Panels kurz

  • Kampagnen-Status — Gesamtfortschritt als Ring; nie bei 0 %, wächst mit jedem platzierten/gestarteten/fertigen Gerät.
  • Übersicht — Karte pro Gerät + Gateway: Standort, Run-Status, Pakete, Live-Werte, SF-Sweep-Leiste. Antippen wählt aus und öffnet das Detail-Panel darunter.
  • Ausgewähltes Gerät / Gateway — Live-Signal sofort sichtbar, Standort, Fotos, Run-Status, Sweep-Fortschritt, Geräte-Status (letztes Paket, gemessenes Sendeintervall, Konfig-Downlink); Platzieren/Umsetzen, Run starten/stoppen, Gateway umsetzen. Auswahlfeld oben rechts als Alternative zum Antippen der Karte.
  • Phase/SF-Wechsel (einklappbar) — Alle Geräte auf festes SF oder ADR umschalten.
  • Funkumgebung (einklappbar) — läuft immer passiv mit, kein Start/Stopp nötig; zeigt eigene vs. fremde Frames sowie CAF je Kanal/SF.
  • Downlink-Loopback (einklappbar) — Bestätigten Downlink senden; ACK-PDR messen.
  • Geräte-Registrierung (einklappbar) — Neue OTAA-Geräte in ChirpStack anlegen.
